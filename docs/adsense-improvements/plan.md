# 개선 계획
공개 콘텐츠의 검증 가능한 설명과 가독성을 높이고, 점검에서 확인한 색인·출생시간 처리 문제를 해결한다. 기존 경로와 서비스를 유지하며 운영자 경력·후기·검수 이력을 만들지 않는다.
1. 과학·건강·투자 관련 단정과 출처 없는 경험 주장을 점검하고 수정한다.
2. 핵심 가이드에 실제 계산 방식과 가상 예시, 참고 자료를 추가하고 제작·수정 기준을 공개한다.
3. 칼럼 스타일, 테스트 페이지 색인, 광고 대상 범위를 정리한다.
4. 출생시간 미상 처리 회귀 검증과 프로덕션 빌드, 실제 화면 점검을 수행한다.
5. 의미 단위로 커밋하고 배포 가능 상태와 외부 계정 확인 항목을 보고한다.
