# 판단 기록
- 2026-09-15 사용자가 점검한 항목 전체 수정을 요청했다.
- 운영자 실명·자격·검수 경력은 제공되지 않았다. 현재 프로젝트에서 확인 가능한 제작 방식과 오류 접수 절차만 설명한다.
- 원래 있던 미추적 CSV와 결과품질개선 지침서는 수정·커밋하지 않는다.
- Search Console 최신 계정 상태와 애드센스 자동 광고 설정은 소스만으로 변경·검증할 수 없다.
- 개인화 결과는 공개 색인하지 않고 가상 사례로 서비스 설명을 강화한다.

- 미상 시간의 임의 정오 변환을 제거하고 API의 이전 클라이언트 플래그도 처리한다. 대운 시작 나이는 미상일 때 생략한다.
- 음력 초하루 00:10 입력의 이전 날짜 변환 예외를 테스트로 재현하고 양력 변환 후 시간 보정하도록 수정했다.
- 승인 전 전역 자동 광고 스크립트를 제거했다. ads.txt와 소유권 확인 메타는 유지한다. 승인 후 본문 광고 배치는 별도로 설정해야 한다. Google 공식 연결 안내는 메타 확인 방식을 지원한다.
- next.config의 빈 experimental.turbo 구식 설정을 제거했다. 기능 변경은 없다.
- 로컬 .env.local의 서비스 계정 JSON이 dotenv의 이중 인용에서 줄바꿈으로 변형되는 오류를 확인했다. 비밀 값을 출력하지 않고 단일 인용으로 교정했다. 키는 변경하지 않았고 환경 파일은 커밋 대상이 아니다.
- 기존 Vercel 직접 배포 인증은 만료됐다. 기존 Git 원격의 인증·접근은 가능하며 자동 배포 경로를 확인한다. 새 호스팅 서비스로 이전하지 않는다.

- 최종 npm test 6개 통과. npm run build 성공, 87개 정적 페이지 생성 및 Firebase Admin 정상 초기화.
- 생성 HTML 11개 표본에서 h1·예시·광고 스크립트 제외·테스트 noindex를 확인했다.
- 390px 모바일에서 칼럼 소제목 24px, 본문 17px, 문단 간격 20px을 확인했고 계산표 가로 넘침이 없었다.
- 원격 이전 커밋의 Vercel 자동 배포 성공 기록을 확인했다. 검증된 수정본을 기존 Git 원격에 반영한다.
- AI API·Firestore 실제 쓰기와 사용자 계정의 심사 요청은 실행하지 않았다.
